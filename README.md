## 🚀 About

SkillProof is a career platform built for **Bangladesh** that helps candidates prove their skills, build a verified Skill Passport, and get hired. Companies post jobs, search verified talent, and run interviews, while administrators govern the platform end-to-end.

---

## ✨ Features

- **Skill Verification** — universal assessments with evidence upload and admin review.
- **Skill Passport** — verifiable passport ID with QR code and public lookup.
- **Career Roadmap** — templated learning paths with module exams.
- **Career Intelligence** — ML-driven scoring of employability, strengths, and skill gaps.
- **AI Career Profile** — auto-generated profile from CV, skills, and experience.
- **CV Parsing** — upload a resume (DOCX/PDF) and auto-fill the profile.
- **Job Portal** — candidates browse and apply; companies post, edit, and shortlist.
- **Interview System** — scheduled sessions with AI-graded answers and downloadable reports.
- **Candidate ↔ Company Messaging** — built-in realtime chat.
- **Admin Governance** — taxonomy, audit logs, analytics, employer/company verification, RBAC.

---

## 🧑‍💻 User Roles

| Role | What they do |
| --- | --- |
| **Candidate** | Builds a verified profile, follows roadmaps, applies for jobs, attends interviews. |
| **Company / Recruiter** | Posts jobs, searches verified candidates, manages applications and interviews. |
| **Administrator** | Verifies skills, reviews passports, manages users/companies, monitors analytics. |

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, React Router
- **Backend:** Supabase (Auth, Postgres, Storage, Realtime)
- **AI Layer:** PHP AI Gateway with an external AI provider for natural-language explanations
- **Mobile:** Android (APK distribution)
- **SMS / OTP:** BDApps (Bangladesh SMS provider)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Create a production build
npm run build
```

Create a `.env` file based on `.env.example` and fill in your Supabase and AI provider credentials before running locally.
